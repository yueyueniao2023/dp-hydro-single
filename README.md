# dp-hydro-single
基于动态规划的水电站单库调度年最大发电量及对应调度序列计算程序

## 项目简介

本项目通过动态规划（Dynamic Programming）算法，求解单个水电站在一年内的最优调度策略，
以最大化年总发电量。属于研究生阶段学习水资源优化调度的入门实践项目。

## 问题描述

- **目标**：在满足水库库容约束、发电流量约束等条件下，求解全年各时段的最优放水策略，
  使年总发电量最大。
- **方法**：将全年划分为若干时段（如月/旬），以水库蓄水量为状态变量，
  放水量为决策变量，采用逆序递推的动态规划方法求解。

## 技术栈

- 语言：Java
- 算法：动态规划（DP）
