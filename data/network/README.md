# 四库合成数据

**教学合成数据，非真实电站资料。**

- [reservoirs.csv](reservoirs.csv)：水位边界、网格、严格初末水位、线性库容斜率、下泄边界、最大发电流量、装机、效率和固定尾水位。
- [connections.csv](connections.csv)：有向连接；A→B、D→B、B→C。每条连接传递上游全部总出库，包括弃水。只支持汇流，不支持把全部流量复制到多个下游的分流。
- [inflows.csv](inflows.csv)：6个时段，每期1日。A、D是各自上游集水区天然来水；B、C仅是未被上游覆盖的新增集水区来水。
- CSV允许空行和#注释，固定表头，不支持含引号或嵌入逗号的字段。所有单位见表头。

`V(亿m³)=min_storage + storage_slope × (Z-min_level)`。恒定中间水位路径(201,141,91,181)每期均满足水量与下泄边界，因此本数据在所选网格上至少存在一条严格初末可行路径。

最小下泄是本期平均总下泄下限，可理解为简化的生态/下游用水要求；总泄流上限代表简化泄洪能力。没有额外时变水位限制；水位上下限同时约束期初和期末。所有库每期允许在全水位范围内转移，未另设爬坡限制。详见[完整教程](../../docs/network-tutorial.md)。
