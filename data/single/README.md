# 单库示例数据

原始输入继续使用 [../hydro_basic_data.xlsx](../hydro_basic_data.xlsx)，不复制、不改变内容，保持已有入口兼容。原Excel的真实来源未在本次任务中核实。

- 第1表：C2:C37，36旬天然来水，m³/s。
- 第2表：A5起整数水位，B1:K1为小数位；矩阵值为库容（亿m³）。
- 第3表：**A4起**整数尾水位；矩阵值为流量（m³/s），正数项有效。
- 第4表：D2:D37，原参考旬末水位，用于可选绘图。

尾水原表最低流量350 m³/s，旧模型允许188 m³/s，却静默用曲线边界值。现在读取原表全部有效行，并使用 [tailwater-low-flow.csv](tailwater-low-flow.csv) 显式补齐 (188 m³/s,666.6 m) 至原表(350 m³/s,667.3 m)。补点是**教学合成数据，非真实电站资料**；原曲线其余部分不变，不允许越界外推或取端点掩盖缺失数据。

时间采用2025非闰年的旬天数，仅借用日历：上/中旬10天，下旬为月天数减20；共365天。水位790～850 m，步长0.5 m，初始830 m，目标840 m；总下泄188～5000 m³/s，最大发电流量5000 m³/s，装机3600 MW，综合系数8.5 kW/(m³/s·m)。见[单库教程](../../docs/single-tutorial.md)。
